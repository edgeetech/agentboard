## DISCOVERY

### Reminders

- What is the primary user goal on this surface?
- What states must be designed: empty, loading, error, partial, success?

### Review Dimensions

- user goal
- state coverage

## PLANNING

### Reminders

- Reuse design system primitives before introducing new ones.
- Plan keyboard-only and screen-reader paths.

### Review Dimensions

- design-system reuse
- a11y plan

## EXECUTING

### Reminders

- Match focus order to visual order.
- Do not ship a spinner when you can ship a useful skeleton.

### Review Dimensions

- focus order
- loading affordance

## VERIFICATION

### Reminders

- Tab through the surface; record any focus traps.
- Run the surface at 200% zoom and at min supported width.

### Review Dimensions

- keyboard trace
- responsive proof
