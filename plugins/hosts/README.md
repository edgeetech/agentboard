# AgentBoard Host Integrations

Target home for host integrations such as Claude Code, Codex, Copilot, editor extensions and desktop launchers.

Current host implementations remain in `plugins/claude-code`, `plugins/codex` and `plugins/copilot` until the packaging/distribution plan is implemented.

The target host package scaffolds under this directory declare the current legacy path, intended target path and host responsibilities. They are manifest-only until launcher packaging is migrated.
